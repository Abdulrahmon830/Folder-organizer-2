# Folder Organizer

A fast and efficient CLI tool built in Go that automatically organizes files in a target directory into categorized subfolders based on their file extensions.

## 🚀 Features

- Automatically scans a target directory for unorganized files.
- Categorizes audio files (`.mp3`, `.aac`, `.wav`) into a `musics` folder.
- Easily extensible for other file formats (images, documents, videos, etc.).
- Robust error checking during file operations.

## 🛠️ Prerequisites

- [Go](https://go.dev/doc/install) (version 1.18 or higher recommended)
